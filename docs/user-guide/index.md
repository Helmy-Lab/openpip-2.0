# User guide

This guide is for anyone using an openPIP portal to look up proteins and their
interactions. No account is needed to search, explore or download.

| To | Read |
|---|---|
| Find a protein's interactions, filter the network and read the result tables | [Searching and exploring networks](searching.md) |
| Look up a single protein: structure, sequence, annotations | [Browsing proteins](proteins.md) |
| Download a dataset or the results of a search | [Downloading data](downloading.md) |
| Keep, share and discuss networks | [Accounts, saving and sharing](accounts.md) |

Each portal is set up by its own team, so its name, colours, example searches
and the data it holds differ from portal to portal. Some features, such as
tissue expression, appear only where the portal's data includes them.

If you use a portal's data in your work, cite the dataset's publication and
openPIP; see [Citing openPIP](../about/citation.md).
