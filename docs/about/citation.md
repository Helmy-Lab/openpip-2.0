# Citing openPIP

If you use openPIP, or data served through an openPIP portal, in published
work, please cite the paper that describes the platform:

> Helmy M, Mee M, Ranjan A, Hao T, Vidal M, Calderwood MA, Luck K, Bader GD.
> **OpenPIP: An Open-source Platform for Hosting, Visualizing and Analyzing
> Protein Interaction Data.** *Journal of Molecular Biology* 434(11):167603
> (2022). [doi:10.1016/j.jmb.2022.167603](https://doi.org/10.1016/j.jmb.2022.167603)

```bibtex
@article{helmy2022openpip,
  author  = {Helmy, Mohamed and Mee, Miles and Ranjan, Aniket and Hao, Tong
             and Vidal, Marc and Calderwood, Michael A. and Luck, Katja
             and Bader, Gary D.},
  title   = {{OpenPIP}: An Open-source Platform for Hosting, Visualizing and
             Analyzing Protein Interaction Data},
  journal = {Journal of Molecular Biology},
  volume  = {434},
  number  = {11},
  pages   = {167603},
  year    = {2022},
  doi     = {10.1016/j.jmb.2022.167603}
}
```

## Citing a dataset

Each dataset hosted in a portal comes from its own publication. Cite that
publication for the data itself. A portal lists each dataset's citation on its
Downloads page, and the tab-delimited (PSI-MI TAB) download of a dataset opens
with `#` comment lines naming the publication to cite. The SIF and CSV
downloads carry no citation, so record it yourself if you use those formats.
