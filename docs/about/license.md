# License

!!! warning "openPIP 2.0's license has not been chosen yet"

    This repository does not yet include a `LICENSE` file. Until the project
    maintainers publish one, no license has been granted for this code.

## What is known

- **The original openPIP**
  ([github.com/BaderLab/openPIP](https://github.com/BaderLab/openPIP)) has a
  `LICENSE` file containing the MIT license, and GitHub labels the repository
  MIT because of it. That file is the license of the Symfony Standard Edition
  skeleton the project was built on. Its copyright line names Symfony's author
  (“Copyright (c) 2004-2016 Fabien Potencier”), not the openPIP authors. The
  file arrived in the repository's first commit (May 2016), along with the rest
  of the skeleton.
- **The openPIP paper** (Helmy et al., 2022) says the platform is “freely
  available” and links to the source code. It does not name a software
  license. The article itself is published under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). That covers the
  text of the paper, not the code.

Choosing a license for openPIP 2.0 is up to the project maintainers. This page
will be replaced by the license text once they decide.
